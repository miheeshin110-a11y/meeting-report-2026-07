1. 대표 보고 시 우선 확인할 사항

  1. 미디어커머스 — 오늘 확인할 결과물: 지난주 ‘다음 경영회의’ 보고 요청인 프리 편성 확대안 및 W 직매입·PPL 방식의 매출·이익·리스크 비교 미확인. 이번 주 일반 편성 개선 방향만으로 해당 요청의 완료 처리 불가. [M6 핵심 요청·액션 1, S p.13–19]
  2. 제품팀 — 회의자료 준비 안 됨: 이번 자료 p.20에 표지만 존재. 홍화 QA·10/14 출시 준비, 신제품 견적·수요예측·발주 연결, 제품별 일정 변경 결과 확인 불가. 과거 회의록을 이번 제품팀 보고로 대체하지 않음. [M6 제품·액션 2·3·8, S p.20–21]
  3. 글로벌 — 진행 현황은 있으나 승인 근거 미흡: 일본 통관·3P 추가 통관·Trial 매대 계획은 확인. 거래처별 초도 수량·조건·일정·손익·마케팅 예산을 묶은 자료와 도쿄타워 총비용·회수 계획 미확인. 기한은 다음 BPR 또는 사전 승인으로, 일괄 기한 초과 판정 제외. [M6 글로벌·액션 6·7, S p.31]
  4. 이커머스 — 분석은 개선, 지난주 점검 종결은 미확인: 광고 확대·유지·개선 구분 및 10/16 재점검 계획 확인. 반면 RS·네이버 수수료 중복 여부의 점검 결론과 제품별 과거 활동 이력 연결표 미확인. KPI 과제의 다음 BPR 기한과 ‘다음 결산’ 기한을 구분할 필요. [M6 이커머스·액션 4·5, S p.8–11,27–29]

  • 미언급 연결 이슈: 프리는 CVR 8.98%인데 AOV는 직전 주 대비 -63.1%, 공헌이익률은 44.5%. 저단가 구성·채널 믹스의 영향 가능성은 가설. 주문별 구성 확인 없이 광고 증액이나 방송 확대의 효과 단정 불가. [S p.11]

9-3. 점검·미언급 이슈·우선 조치

  • 상태 표기의 반복 문제: ‘실제 완료일’ 칸에 미래 날짜와 예정·미완료 건 혼재. 예정일/실제 완료일/결과를 분리하고, 연기 시 이전 약속일·새 기한·사유 보존 제안. [S p.36]
  • 품목 손익 연결: p.33 상품표에 알파CD 프로 매출 약 127만원이 있으나 p.35 품목 그래프에는 해당 품목이 보이지 않음. 기타 합산 여부와 총 공헌 약 430만원의 품목별 연결 확인 필요. 전체 누락 오류로 단정하지 않음.
  • 제안: 유통사업 담당이 4,000만원 전망을 확정 PO/협의/신규 가정으로 나누고, 오늘 예정인 다이소 결과부터 갱신. 월말 목표 미달을 이미 확정한 것으로 보고하지 않음.

10. 팀 간 연결과 다음 보고의 완료 기준

  1. 신제품 견적·수요·발주: 제품팀 최종 견적 수령 → 미디어·이커머스 수요 제출 → 제품·SCM 결재/발주. 각 단계의 수령일·전달일·담당·남은 조건을 한 표로 연결. 견적 확정 전부터 후속 팀을 미이행으로 분류하지 않음.
  2. 프리 확대·쿠팡 조건 변경: 공헌이익률, 매출 규모, 재고 회수, 추가 광고·PPL 비용을 동일 기준으로 비교한 뒤 결정. 높은 비율 지표나 단독 ROAS만으로 확대 승인하지 않는 방식 제안.
  3. 일본·다이소 출시 연결: 글로벌/유통의 거래처 계획과 제품팀의 규격·품질·MOQ·납기 계획을 연결. 거래처 입점 확정과 제품 공급 가능의 양쪽 조건 확인.
  4. 약속 종결 표준: 지난주 요청 / 담당 / 원래 기한·조건 / 이번 결과 / 완료 증거 / 남은 일 / 새 기한을 고정 유지. 새 양식 도입 시에도 과거 미종결 과제 삭제 금지.

회의에서 받을 답변: ① 프리 비교안 제출 여부와 제출일 ② 제품팀 최신 자료 제출일 ③ 견적·수요예측·발주의 현재 병목 ④ 수수료·광고비 대사 완료 예정일 ⑤ 일본·도쿄타워 승인안 준비일 ⑥ 다이소 당일 결과와 헬씨위드 일정 변경 사유. 담당 개인·새 기한은 회의에서 확정 필요.

발송 관리: 제품팀은 자료 미제출 상태로 공유 문구에 반영 필요. KPI 전체 미업데이트 또는 특정 팀의 실제 업무 미실행으로 확대 표기하지 않음. 본 공유본은 사용자 요청에 따라 GitHub 게시·Slack 공유 대상으로 등록.

  • GitHub 보고서: 9/2·9/7·9/14·9/21·10/6 검토 보고서의 기존 검토 이력 및 10/6 미종결 항목과 대조. 저장소 원격 상태 확인. 이번 판단은 최신 자료로 재판정. 별도 10/12 운영 회의록을 ‘지난주 약속’으로 사용하지 않음. 삭제하기로 한 해석 오류 문서 사용 제외.
  • 신규 지표·같은 정의의 과거 값이 없는 경우 미확인으로 표시. 원자료의 집계 기간·모집단·매출 인식·VAT·원가·광고 포함 차이가 해소되지 않은 값은 직접 증감 계산 제외. 같은 수치 반복만으로 미업데이트 단정 금지.
